# ☁️ zmod.link Cloud

## Kostenloser Dienst zur Verwaltung von 3D-Druckern

> 🚀 **Vollständig kostenloser, nicht kommerzieller Dienst**

---

### 🆓 Kostenloser Tarif
Jeder registrierte Benutzer erhält **2 Drucker kostenlos**.

---

### 💡 Wie kann das Druckerlimit erhöht werden?

Benötigen Sie mehr als 2 Drucker? Sie können Ihr Limit mit einer von zwei Möglichkeiten zur Unterstützung erhöhen:

#### Option 1: Das Projekt unterstützen ⭐
- Vergeben Sie einen ⭐ **Stern** für das [Z-Mod](https://github.com/ghzserg/zmod)-Repository auf GitHub.
- Machen Sie einen Screenshot als Nachweis.
- Ein Stern gewährt **einen zusätzlichen Drucker**.

#### Option 2: Freiwillige Spende 💰
Kosten: **500 RUB pro zusätzlichem Drucker und Jahr**

Verfügbare Zahlungsmethoden:

| Methode | Details | Wichtig |
|--------|---------|-----------|
| **🇷🇺 Russische Rubel** | [Zahlungslink](https://pay.cloudtips.ru/p/3cbf9e9f) | Geben Sie Ihren zmod.link-**Benutzernamen** als Absendernamen an |
| **₿ Bitcoin** | `17wXTd9BqYp1K3zCLTxVyGLEXUDjf7XNLL` | Überweisen Sie den BTC-Gegenwert von **500 RUB** pro Drucker* |
| **Boosty** | <a href="https://boosty.to/ghzserg">Über Boosty unterstützen (internationale Visa/Mastercard)</a> | ≈ Überweisen Sie den Gegenwert von **500 RUB** in USD pro Drucker* (ca. 5 $) |

> \* Der BTC-Betrag hängt vom aktuellen Wechselkurs ab. Berechnen Sie den Gegenwert von **500 RUB** zum Zeitpunkt der Überweisung.
> Beispiel (ungefähr): Bei 1 BTC ≈ 4.200.000 RUB entsprechen 500 RUB etwa **0,00012 BTC** pro Drucker.

**Beispiele für eine Limiterhöhung:**

- 500 RUB / ~0,00012 BTC → +1 Drucker (insgesamt: 3 Drucker)
- 1.000 RUB / ~0,00024 BTC → +2 Drucker (insgesamt: 4 Drucker)
- 1.500 RUB / ~0,00036 BTC → +3 Drucker (insgesamt: 5 Drucker)
- usw.

### 📬 Wie kann eine Limiterhöhung beantragt werden?

Senden Sie eine E-Mail an: **📧 [add@zmod.link](mailto:add@zmod.link)**

Bitte geben Sie Folgendes an:

- Ihren zmod.link-**Benutzernamen**
- Die gewählte Unterstützungsmethode (GitHub-Stern / RUB-Spende / BTC-Spende)
- Bei einem GitHub-Stern: den Screenshot als Anhang
- Bei einer Spende: Betrag, Datum und **Transaktions-Hash** (bei BTC)

---

### ❤️ Wofür werden Spenden verwendet?

Alle Beiträge werden ausschließlich verwendet für:
- 🔁 Verlängerung und Skalierung des Hostings
- ⚡ Erhöhung der Serverkapazität und -leistung
- 🛠 Laufende Entwicklung und Wartung des Projekts
