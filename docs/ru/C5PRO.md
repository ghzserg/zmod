## Важные особенности

- Принтер всегда работает с **4 цветами** (T0, T1, T2, T3). Все четыре слота доступны в меню выбора.
- Чтобы включить камеру, нужно использовать `CAMERA_ON VIDEO=video67`.
- Возможен вылет Klipper. Решение: `Профиль процесса` -> `Прочее` -> `Выходной G-code` -> `Исключение моделей` — выключить галочку.
- Если вы отправлояете `3mf`, то используйте только режим с родным экраном
- Если вы отправлояете `gcode`, то при печати с родным экраном сменить порядок цветов проблематично.
- Вместо макроса `CLOSE_DILALOGS` (медленное закрытие) всегда используйте `FAST_CLOSE_DILAOGS` (быстрое закрытие).
- Макрос `NEW_SAVE_CONFIG` не работает.
- Нет поддержки Klipper 13

## Меню печати

Это окно открывается само, когда вы начинаете печать.

<img width="562" height="593" alt="{A688018F-CB9C-4EFA-9431-AAE9E2DE842E}" src="https://github.com/user-attachments/assets/92cababe-52b1-49aa-aea3-1ad6ddf03cfe" />

**Как понять, что тут написано:**

- `Cube.gcode` – это имя файла, который печатается.
- `1` – это первый цвет из файла. Он печатается филаментом из катушки 2 (оранжевый PETG).
- `2` – это второй цвет. Он печатается филаментом из катушки 4 (серый PLA).
- `3` – третий цвет, печатается с катушки 1 (черный PETG).

### Построение карты стола и AUTO PA

В меню печати есть две важные кнопки:

**Leveling (Карта стола):**

- `Снять карту стола` — перед печатью будет выполнено автоматическое построение карты стола.
- `Не снимать карту стола` — будет использована ранее сохранённая карта.

**Auto PA (Автоматический подбор Pressure Advance):**

- Если кнопка `Auto PA` активна (зелёная), то **перед началом печати** принтер автоматически подберёт оптимальное значение Pressure Advance для каждого используемого экструдера.
- Процесс занимает несколько минут, но значительно улучшает качество углов и тонких элементов.
- Если `Auto PA` выключен, будут использованы значения PA из слайсера.

Автоматическая калибровка идет от 0.01 до 0.04 и для вязких пластиков таких как PETG бесполезна

## Тонкая настройка

Нужно сначала отключить родной экран принтера с помощью макроса `DISPLAY_OFF`.

**Как найти эти настройки:**

1. Нажмите на вкладку «Конфигурация».
2. Найдите и откройте папку `mod_data`.
3. В этой папке найдите и откройте файл `filament.json`.

<img width="480" height="826" alt="{F5EAE8D4-1A9F-4E6C-99A1-B609A331E82D}" src="https://github.com/user-attachments/assets/4b7b5f91-b3ff-4c75-824d-4ec06e2ac6de" />

| Параметр | По умолчанию | Описание |
|---|---|---|
| `temp` | 220 | Температура, до которой разогревается сопло для смены филамента. Значение зависит от типа материала |
| `temp_manual` | 250 | Температура продувки в ручном режиме (при загрузке через меню). |
| `temp_wait` | 120 | Температура простоя — до неё остывает сопло после продувки. |
| `filament_drop_length` | 50 | **Длина сброса.** Сколько миллиметров пластика принтер выдавит в мусорную корзину, чтобы очистить сопло от старого цвета. |
| `filament_tube_length` | 295 | Длина загрузки филамента при вставке новой катушки. |

| ABS | 250 | 280 | 150 |

| SILK | 220 | 250 | 120 |

### Расширенные параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `trash_x` | 275.0 | Координата X мусорной корзины. |
| `trash_y` | 254.0 | Координата Y мусорной корзины. |
| `trash_z` | 10.0 | Координата Z мусорной корзины. |

## Глобальные параметры

Чтобы окно выбора цвета не показывалось при начале печати, используйте глобальный параметр **SILENT**:

- `0` — показывать окно (по умолчанию)
- `1` — не показывать окно, использовать ранее заданные цвета
- `2` — не показывать окно, не использовать систему подачи

```
SAVE_ZMOD_DATA SILENT=1
```

Чтобы включить сканирование gcode-файлов на наличие информации об инструментах, цветах и материалах, используйте параметр **SCAN_FILE_COLORS**. Вы также можете установить значение `2`, чтобы проверять только данные, подготовленные скриптом слайсера, без сканирования файлов целиком:
```
SAVE_ZMOD_DATA SCAN_FILE_COLORS=1
```

Чтобы включить **автоматическое сопоставление цветов** из gcode-файла с физическими катушками, используйте параметр **AUTO_ASSIGN_COLORS**. Для работы этой функции необходимо активировать сканирование файлов. Использование значения `30` приведёт к прерыванию печати в тихом режиме, если возникнут любые проблемы с автоматическим назначением:
```
SAVE_ZMOD_DATA AUTO_ASSIGN_COLORS=30
```

Вы можете настроить собственные значения для прерывания печати в тихом режиме, сложив следующие числа:

- `2` — Хотя бы один материал не совпадает (например, в gcode указан ABS, а у вас загружен только PLA)
- `4` — Хотя бы один цвет не совпадает совсем (обычно из-за того, что сканирование файлов отключено)
- `8` — Хотя бы один цвет совпадает плохо
- `16` — Одна и та же физическая катушка была назначена более чем одному индексу инструмента в файле

**Если отключено сканирование файла**, то принтер не знает сколько экструдеров используется, и поэтому **Auto PA будет запущено для всех катушек**

## Добавить свои типы филамента

Чтобы эти настройки работали, нужно отключить родной экран принтера с помощью макроса `DISPLAY_OFF`.

Для добавления нового типа филамента в `mod_data/user.cfg` добавить:

```
[zmod_color]
filament_NEWTYPE: 300
```

Где `NEWTYPE` заменить на нужный вам тип филамента (например `HIPS`), а число — это температура экструдера для загрузки, выгрузки и продувки этого филамента. На основе этого значения автоматически рассчитаются `temp_manual` (+30) и `temp_wait` (−100).

Для скрытия типа филамента в `mod_data/user.cfg` добавить:

```
[zmod_color]
hide_filament_types: XXX,YYY,ZZZ
```

Где `XXX`, `YYY`, `ZZZ` заменить на нужные вам типы филамента (например `PLA-CF,PETG-CF,SILK`). Это можно использовать для скрытия типов по умолчанию или типов, которые вы добавили вручную. При этом тип филамента не отключается, а только скрывается в меню выбора типа.

## Калибровка экструдеров

Калибровка экструдеров позволяет принтеру точно знать положение каждого из четырёх сопел относительно друг друга. Это необходимо для качественной многоцветной печати.

**Когда нужно калибровать:**
- После замены или ремонта экструдера.
- Если вы заметили, что цвета не совпадают на модели (смещение по X, Y или Z).

**Как запустить:**

1. **Снимите печатную пластину** со стола!
2. Запустите макрос `CALIBRATE_EXTRUDERS` из меню или введите в консоли:
   ```
   CALIBRATE_EXTRUDERS
   ```
3. Появится окно подтверждения. Нажмите `OK`.

**Что произойдёт:**

- Принтер выполнит (G28).
- Нагреет стол до 65°C.
- Поочерёдно возьмёт каждый из 4 экструдеров (T0–T3).
- Для каждого экструдера: нагреет сопло, выполнит продувку, очистит о резинку, затем с помощью датчиков определит точные координаты X, Y и Z.
- Результаты автоматически запишутся в файл `rw/extruder.json`.
- По окончании принтер выведет в консоль найденные смещения для каждого экструдера.

**Дополнительные параметры** (для продвинутых):

| Параметр | По умолчанию | Описание |
|---|---|---|
| `BED_TEMP` | 65.0 | Температура стола при калибровке |
| `SEARCH` | 14.0 | Радиус поиска датчика (мм) |
| `HOVER` | 0.6 | Высота зависания над точкой |
| `SAFE_Z` | 10.0 | Безопасная высота Z |

**Пример с параметрами:**

```
CALIBRATE_EXTRUDERS BED_TEMP=70 SEARCH=12
```

> **Внимание!** Не прерывайте калибровку. Процесс занимает несколько минут.

## Калибровка VFA

Калибровка VFA (Vertical Fine Artifacts) позволяет уменьшить вертикальные артефакты на поверхности печати, вызванные резонансами шаговых двигателей.

**Как запустить:**

Введите в консоли:
```
CALIBRATE_VFA T=0
```

Где `T=0` — номер экструдера (0–3), который будет использоваться во время калибровки.

**Что произойдёт:**

- Принтер возьмёт указанный экструдер.
- Обнулит все G-code смещения.
- Переместит голову в центр стола (X130 Y130).
- Запустит автоматическую калибровку резонансов (`STEPPER_RESONANCE_FACTORY_CALIBRATE`).
- Вернёт экструдер на место.
- Сохранит конфигурацию (`SAVE_CONFIG`).

> **Совет:** Рекомендуется выполнять калибровку VFA при появлении видимых вертикальных полос на поверхности печати.

## Макрос `T_INFO`

Макрос `T_INFO` показывает текущее состояние всех экструдеров и датчиков принтера.

**Как запустить:**
```
T_INFO
```

**Что будет выведено в консоль:**

```
// T0: home
// T1: HEAD
// T2: home
// T3: home
// Door: Close
// Top: Close
// Offset: X=0.000 Y=0.000 Z=0.061 (0.000)
```

**Как читать:**

- `home` — экструдер стоит на своём месте (в парковочном кармане).
- `HEAD` — экструдер установлен на печатающую голову.
- `?` — неопределённое состояние (датчики не сработали).
- `ERROR (both)` — ошибка: экструдер одновременно и дома, и на голове (рассинхрон датчиков).
- `Door` — состояние передней дверцы (`Close` / `Open`).
- `Top` — состояние верхней крышки (`Close` / `Open`).
- `Offset` — текущие G-code смещения по осям X, Y, Z.

## Режимы вентиляции

Creator5 Pro оснащён системой вентиляции камеры с несколькими вентиляторами. Правильное управление вентиляцией критически важно для качества печати разных материалов.

**Внешний забор (PLA, TPU):**

Макрос `AIR_CIRCULATION_EXTERNAL` — включает вытяжку из камеры и подачу свежего воздуха. Нужен для PLA и TPU, чтобы пластик быстро остывал и не размягчался от тепла камеры.
```
AIR_CIRCULATION_EXTERNAL
```
| Вентилятор | Скорость |
|---|---|
| `chamber_fan` (вытяжка) | 0.5 |
| `chamber_cool_fan` (охлаждение) | 0.7 |
| `chamber_heat_fan` (нагрев) | 0.0 |
| `chamber_loop_fan` (циркуляция) | 0.0 |

**Внутренняя циркуляция (ABS, ASA):**

Макрос `AIR_CIRCULATION_INTERNAL` — включает внутреннюю циркуляцию и подогрев камеры. Нужен для ABS и ASA, чтобы избежать расслоения и коробления от перепадов температур.
```
AIR_CIRCULATION_INTERNAL
```
| Вентилятор | Скорость |
|---|---|
| `chamber_fan` (вытяжка) | 0.0 |
| `chamber_cool_fan` (охлаждение) | 0.0 |
| `chamber_heat_fan` (нагрев) | 0.9 |
| `chamber_loop_fan` (циркуляция) | 0.3 |

**Остановка вентиляции:**
Макрос `AIR_CIRCULATION_STOP` — полностью выключает все вентиляторы камеры.
```
AIR_CIRCULATION_STOP
```

### Куда добавить макросы вентиляции

> **Рекомендация:** Лучше всего добавить вызовы макросов вентиляции в **код филамента** в слайсере. Это обеспечит автоматическое переключение режима при смене материала.

**В OrcaSlicer:**

1. Откройте настройки филамента.
2. Перейдите на вкладку «Настройки филамента».
3. В поле **Начальный G-код филамента** добавьте нужный макрос:
   - Для PLA: `AIR_CIRCULATION_EXTERNAL`
   - Для ABS: `AIR_CIRCULATION_INTERNAL`
   - Для TPU: `AIR_CIRCULATION_EXTERNAL`

**Пример для PLA:**
```gcode
; Filament start gcode
AIR_CIRCULATION_EXTERNAL
```

**Пример для ABS:**
```gcode
; Filament start gcode
AIR_CIRCULATION_INTERNAL
```

Таким образом, при многоцветной печати с разными материалами вентиляция будет автоматически переключаться в нужный режим для каждого экструдера.
