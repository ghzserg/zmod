    Version History¶

    Version 1.7.5¶

    28.10.2026

    • Z-Mod: 3MF support
    • Z-Mod: With 3MF, color mapping is instant — the preprocessor is no longer needed
    • Z-Mod: Fast KAMP — enabled automatically and works without slow object exclusion. For 3MF the KAMP data is available instantly, for G-code — after the file is scanned
    • C5Pro: Support for up to 100 colors in a file, mapped to 4 extruders
    • New macro PLUGINS — plugin management menu
    • New macro _USER_PREPARE_PRINT — called before the file is sent to print
    • New global parameter PURGE_ALL_EXTRUDERS — purge all used extruders at print start
    • New global parameter UNUSED_EXTRUDERS_OFF_TIME — turn off heating of idle extruders after a set time
    • The support Telegram bot @zmod_help_bot is now AI-powered
    • Fluidd: 3MF support
    • Mainsail: 3MF support
    • Moonraker: 3MF support
    • Bug fixes

    Upstream contributions:

    • Fluidd: prompt action button grouping #1977
    • Mainsail: HEX colors in the third parameter of macro prompts, together with @function3d #2687
    • OrcaSlicer (coming in 2.5.0, currently in beta):
      • Exclude-object outline tolerance is now a user setting #16503
      • Tolerance set to 0.2 mm for AD5M/AD5M Pro, AD5X, Creator 5 / 5 Pro — fewer outline points, more objects per plate without "Timer too close" #16687
      • Post-processing scripts are applied to G-code packed into .gcode.3mf #16464
      • Fixed the first-layer bbox in plate_N.json being shifted on every plate after the first #16860

    • C5Pro: Added a mode without the native screen

    • GuppyScreen: Support for multiple extruders

    Version 0.2.2¶

    17.12.2024

    • New macro FAST_CLOSE_DIALOGS - quickly closes native screen dialogs. Used to close the window at the end of a print or when a print is cancelled. For fast closing, go to "Settings" -> "WiFi icon" -> "Network Mode" on the printer screen and enable "Local Network Only". Implementation: @darksimpson
    • New macro LEVELING_PRINT_FILE - print a file with bed mesh probing from the native screen. For LEVELING_PRINT_FILE, go to "Settings" -> "WiFi icon" -> "Network Mode" on the printer screen and enable "Local Network Only"
    • New macro COLDPULL - cold pull (nozzle cleaning) without force. Implementation of this algorithm
    • New SAVE_ZMOD_DATA parameters:
      • PRINT_LEVELING - probe the bed mesh with the native screen for every print 0-no, 1-yes (0). For bed mesh probing from the native screen, go to "Settings" -> "WiFi icon" -> "Network Mode" on the printer screen and enable "Local Network Only"
      • USE_KAMP - where possible, use an adaptive bed mesh (KAMP) instead of a full bed mesh 0-no, 1-yes (0). Allows using KAMP when the bed mesh is probed over the network from the native screen
      • CLOSE_DIALOGS - automatically close dialogs at the end of a print and on cancel 0-no, 1-yes slowly, 2-yes quickly. For fast closing, go to "Settings" -> "WiFi icon" -> "Network Mode" on the printer screen and enable "Local Network Only" (0).
      • USE_SWAP - use SWAP 0-no, 1-yes (1). If your CPU has not been re-soldered, SWAP is mandatory

    Version 0.1.1¶

    27.11.2024

    • Support for working with the native display turned off. This saves 20 MB of RAM. To enable this mode, call the DISPLAY_OFF macro. Klipper restarts and uses alternative configuration files. It is recommended to probe the bed mesh and save it to the default profile. After a reboot, the screen becomes unavailable after 5 minutes and the bed mesh from the default profile is loaded.
    • Macro MEM - shows how much memory is used and by which application.
    • Macro DISPLAY_ON - returns the screen to the standard mode, the printer reboots
    • Macro LED - turns the light on at 50%
    • Macro LED_ON - turns the light on at 100%
    • Macro LED_OFF - turns the light off
